# Sistema Bancário em C

## Sobre o projeto

Este projeto consiste em um sistema bancário simples desenvolvido em linguagem C, como parte dos meus estudos em Análise e Desenvolvimento de Sistemas (ADS).

O programa simula as operações básicas de um caixa eletrônico por meio de um menu interativo no terminal.

## Funcionalidades

- Consulta de saldo.
- Depósito de valores.
- Saque com validação de saldo disponível.
- Validação de entradas inválidas.
- Exibição do saldo final ao encerrar o programa.

## Tecnologias utilizadas

- Linguagem C
- GCC (compilador)
- Visual Studio Code

## Como executar

1. Instale um compilador C, como o GCC.
2. Clone ou baixe este repositório.
3. Abra o terminal na pasta do projeto.
4. Compile o código:

   ```bash
   gcc main.c -o sistema_bancario.exe
   ```

5. Execute o programa no Windows:

   ```powershell
   .\sistema_bancario.exe
   ```

## Objetivo educacional

O objetivo deste projeto é praticar conceitos fundamentais da linguagem C, como variáveis, estruturas condicionais, estruturas de repetição, `switch`, entrada e saída de dados e validação de informações.

Este é um projeto acadêmico e educacional, sem conexão com contas bancárias reais.
